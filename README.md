# Application Web – Surveillance de la Qualité de l'Air

## Description
Application web cartographique de surveillance de la qualité de l'air en France,
développée dans le cadre du BUT Science des Données (IUT de Carcassonne).

## Fonctionnalités
- Carte interactive temps réel avec IQA de 47+ stations (API WAQI)
- Filtres dynamiques : polluant, période, région, département, commune
- Alertes santé automatiques selon le niveau de pollution
- Statistiques : évolution temporelle, corrélations, top communes
- Prévisions J+1 / J+2 / J+3 par station
- Story Map animée sur 10 ans de données

## Technologies
PHP · JavaScript · Leaflet.js · PostgreSQL · PostGIS · Chart.js · Bootstrap · API WAQI
